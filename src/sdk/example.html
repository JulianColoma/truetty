🔐 KeyPass Auth SDK

Ejemplo de integración en sitio web tradicional

Widget de Autenticación

Este widget demuestra cómo integrar KeyPass Auth en tu sitio web. El usuario escanea el QR con su celular y se autentica automáticamente.

✅ Token de Sesión Recibido

Código de Integración

Así de fácil es integrar KeyPass Auth en tu sitio:

<!-- 1. Agregar contenedor -->
<div id="keypass-widget"></div>

<!-- 2. Incluir SDK -->
<script src="keypass-sdk.js"></script>

<!-- 3. Inicializar -->
<script>
  KeyPassSDK.init({
    elementId: 'keypass-widget',
    serverUrl: 'https://localhost:3443',
    onSuccess: (token) => {
      // Token JWT recibido
      console.log('Token:', token);
      
      // Guardar en localStorage
      localStorage.setItem('sessionToken', token);
      
      // O enviar a tu backend
      fetch('/api/login', {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token}`
        }
      });
    },
    onError: (error) => {
      console.error('Error:', error);
    }
  });
</script>

📋 Instrucciones de Prueba

  1. Asegúrate de que el servidor KeyPass esté corriendo en https://localhost:3443
  2. Abre esta página en tu navegador
  3. Verás un código QR en el widget
  4. Abre la app KeyPass en tu celular
  5. Escanea el código QR con tu celular
  6. Confirma la autenticación en tu celular
  7. El widget mostrará "¡Autenticación Exitosa!"
  8. El token JWT aparecerá debajo del widget
