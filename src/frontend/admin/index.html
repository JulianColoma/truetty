Bienvenido a KeyPass Auth

KeyPass Auth es un sistema de autenticación descentralizada que permite a tus usuarios iniciar sesión escaneando un código QR con su celular, sin contraseñas ni SMS.

Integración del SDK

Copia y pega este snippet en tu sitio web para integrar KeyPass Auth: 

<!-- 1. Agregar contenedor -->
<div id="keypass-widget"></div>

<!-- 2. Incluir SDK -->
<script src="https://cdn.keypass.dev/keypass-sdk.js"></script>

<!-- 3. Inicializar -->
<script>
  KeyPassSDK.init({
    elementId: 'keypass-widget',
    serverUrl: 'http://localhost:3000',
    clientId: 'TU_CLIENT_ID_AQUI',
    onSuccess: (token) => {
      console.log('Token JWT:', token);
      // Guardar token, enviar a tu backend, etc.
    },
    onError: (error) => {
      console.error('Error:', error);
    }
  });
</script>
