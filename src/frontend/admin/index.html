Integración del SDK

Copia este snippet en tu sitio web para integrar KeyPass Auth:

<!-- 1. Contenedor --> <div id="keypass-widget"></div> <!-- 2. SDK --> <script src="https://cdn.keypass.dev/keypass-sdk.js"></script> <!-- 3. Inicializar --> <script> KeyPassSDK.init({ elementId: 'keypass-widget', serverUrl: 'http://localhost:3000', clientId: 'TU_CLIENT_ID', onSuccess: (token) => { console.log('Token:', token); } }); </script>
